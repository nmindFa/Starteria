# Startería - UX Writing

## Tono
- claro
- humano
- directo
- orientado a acción
- con criterio experto

## Reglas
- escribir en español latino
- evitar spanglish innecesario
- evitar mensajes genéricos
- explicar para qué sirve cada actividad
- usar mensajes que orienten y destraben

## Estructura recomendada para feedback IA
1. Qué está bien
2. Qué falta
3. Qué recomienda hacer ahora

## Ejemplos
En vez de:
- Completa este campo

Usar:
- Define aquí la hipótesis más riesgosa: la que, si no se valida, debilita toda la propuesta.

En vez de:
- Tu pregunta no está lista

Usar:
- Revisa si tu HMW deja claro quién está afectado, qué fricción quieres abordar y si abre espacio a soluciones accionables.
