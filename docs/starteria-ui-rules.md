# Startería - UI Rules

## Principios
- mantener secuencia visual por steps
- no romper el flujo con pantallas aisladas
- usar anclas visibles cuando el usuario necesita recordar contexto previo
- diferenciar claramente estados
- priorizar claridad antes que densidad

## Cada módulo debe mostrar
- propósito
- tarea actual
- contexto ancla
- output esperado
- siguiente acción

## Evitar
- formularios largos sin guía
- bloques de texto ambiguos
- demasiados CTA compitiendo
- mensajes de error poco útiles
