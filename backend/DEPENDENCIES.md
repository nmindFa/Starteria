# Backend Dependencies

## Production
- express
- cors
- helmet
- cookie-parser
- zod
- pino
- pino-http
- pino-pretty
- @prisma/client
- dotenv
- uuid

## Dev Dependencies
- @types/express
- @types/cors
- @types/cookie-parser
- @types/uuid
- prisma
- typescript
- tsx

## Install Commands

```bash
npm install express cors helmet cookie-parser zod pino pino-http pino-pretty @prisma/client dotenv uuid
npm install -D @types/express @types/cors @types/cookie-parser @types/uuid prisma typescript tsx
```
